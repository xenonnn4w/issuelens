ISSUE LENS

Privacy policy

Last updated October 12, 2026.

Information we use

Clerk manages your sign-in and account information. Issue Lens stores your account ID with investigations you create, including public GitHub issue content, retrieved repository evidence, reports, response drafts, and usage metrics. Investigations are visible only to the account that created them.

Connections and AI

OpenAI API keys and GitHub tokens you add in Connections remain in your browser tab's session storage. They are sent to the Issue Lens server only for a run and are not saved in its investigation database. In AI mode, issue descriptions, comments, and retrieved code are sent to the configured AI provider to generate a report. GitHub requests retrieve public repository data.

Security and retention

The site uses HTTPS. Clerk session tokens authorize access to saved investigations. Investigation records remain on the server until they are removed; closing your browser tab clears tab-stored connection keys. Do not submit confidential information in public GitHub issue URLs.
