REFERENCE

Documentation

Investigate a GitHub issue

Open New Investigation and paste a public issue URL. The investigator reads its description and discussion, then searches related issues and repository code.

Review the evidence

Findings link to observed sources. Code excerpts point to a fixed commit and line range. Confidence describes an assessment; it does not establish a reproduced root cause.

Approve a response

Edit the response, save changes, and approve the draft. Copy the approved response to GitHub. Editing it requires approval again.

Investigation tools

search_issues
Find related reports in the same repository.
search_paths
Find candidate files using path keywords.
search_code
Search up to eight ranked source files plus cached files. Coverage is recorded.
read_file
Read up to 100 lines from a known file.

Boundaries

Public repositories only. Repository code is read, never executed. The snapshot is current default-branch code. Retrieval mode collects evidence without AI analysis.

Each run allows 36 GitHub requests, 10 model turns, 18 tool operations, and six minutes. Interrupted runs retain collected evidence.
